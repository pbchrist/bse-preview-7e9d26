# Big Shack Entertainment asset provenance

This preview intentionally keeps a source record for every non-user-supplied photographic asset used in the build.

## User-supplied / project-owned
- `assets/big-john-gold-*` — derived from the Big John portrait supplied by Patrick for this project.
- `assets/type/*.svg` — custom outlined display/lockup artwork created for this project so core typography renders identically across devices without redistributing Avenir font files.
- `assets/proof/*.svg` — brand-mark artwork used only as provisional background/experience references; public usage/credit language remains subject to John’s approval.
